우리 학교에 설치하기

자료는 우리 학교 Firebase에만 저장됩니다
만든 사람을 포함해 어디로도 전송되지 않습니다

1
Firebase 프로젝트를 만듭니다.
console.firebase.google.com 에서 [프로젝트 만들기] → 이름은 연수비정산처럼 자유롭게 정하세요. 구글 애널리틱스는 사용 안 함으로 두셔도 됩니다.
2
웹 앱을 추가합니다.
프로젝트 첫 화면에서 </> 모양 아이콘 클릭 → 앱 이름 입력 → [앱 등록]
그러면 const firebaseConfig = { … }가 나옵니다. 중괄호 부분을 통째로 복사하세요.
3
복사한 내용을 아래에 붙여넣습니다.
4
총괄 관리자로 쓸 구글 계정을 적습니다. 학교 전체 그룹을 보고 지울 수 있는 계정입니다.
✅ 설정을 확인했습니다
5
Firebase 콘솔에서 세 가지를 켜 주세요.
  • Authentication → 시작하기 → 이메일/비밀번호 사용 설정
  • 같은 화면에서 Google 사용 설정 (총괄 관리자 로그인용)
  • Firestore Database → 데이터베이스 만들기 → 위치 asia-northeast3
Authentication 열기 Firestore 열기
6
보안 규칙을 붙여넣습니다. 아래 버튼으로 복사해 Firestore → [규칙] 탭에 통째로 붙여넣고 게시하세요.
규칙 탭 열기
규칙을 게시하지 않으면 자료가 누구에게나 열립니다. 꼭 해주세요.
7
설정이 끝난 파일을 내려받아 웹에 올립니다. 아래 버튼을 누르면 위 내용이 모두 들어간 index.html이 저장됩니다. 파일을 편집기로 열어 고치실 필요가 없습니다.
올리신 뒤 Authentication → 설정 → 승인된 도메인에 그 주소를 추가해야 구글 로그인이 됩니다.

사용 순서

담당자가 학교 계정에 설치하고 비밀번호를 정합니다

교원 명단을 추가하고 그룹명을 교원에게 공유합니다

각 교원이 접속 후 지출 내역을 직접 입력합니다

관리자가 전체 현황을 확인하고 엑셀로 다운로드합니다

🛡️ 개인정보 처리 안내
수집하는 항목
· 그룹: 그룹명, 접속용 비밀번호
· 교원: 담당(학년·반 등), 본인 확인용 비밀번호
· 정산 자료: 지출 항목명, 금액, 분류, 입력 일시

이름·이메일 주소를 수집하지 않습니다. 명단은 '1학년 1반'처럼 담당으로만 관리하며, 로그인에도 이메일을 쓰지 않습니다. 주민등록번호·연락처·계좌번호·카드번호도 수집하지 않습니다.
즉 이 서비스에 저장되는 자료만으로는 개인을 특정할 수 없습니다.
이용 목적
자율연수비 집행 현황 확인과 정산 결과 엑셀 산출에만 사용하며, 광고·마케팅 목적으로 사용하지 않습니다.
누가 볼 수 있나요
명단 화면에는 담당(학년·반)만 표시되며, 지출 내역은 본인이 정한 비밀번호를 입력해야 열립니다. 다른 학교(그룹)의 자료는 서로 볼 수 없습니다. 이 비밀번호는 다른 곳에서 쓰는 것을 그대로 사용하지 마시고, 지출 항목명에는 알려지길 원치 않는 내용을 적지 말아 주세요.
국외 이전
· 이전받는 자: Google LLC (Google Firebase)
· 이전 국가: 미국 등 Google이 운영하는 데이터센터 소재 국가
· 이전 시기·방법: 서비스 이용 시점에 정보통신망을 통해 전송
· 이전 항목: 그룹명, 담당(학년·반), 접속용·본인 확인용 비밀번호, 지출 내역
· 이용 목적 및 보유 기간: 자료의 저장·조회, 학년도 종료 후 삭제
· 거부 방법과 효과: 이 서비스를 이용하지 않으시면 되며, 이 경우 기존의 종이·엑셀 방식으로 정산하실 수 있습니다.
보관 장소
Google Firebase(Firestore·Authentication)에 저장되며, 전송 구간은 암호화(HTTPS)됩니다. 서비스 운영 외의 목적으로 제3자에게 제공하지 않습니다.
보관 기간 및 파기
해당 학년도 종료(다음 해 3월) 이후 지난 학년도 자료로 분류되어 삭제될 수 있습니다. 필요한 자료는 학년도가 끝나기 전에 엑셀 다운로드로 보관해 주세요.
열람·수정·삭제
지출 내역은 기록의 신뢰성을 위해 입력 후 수정·삭제할 수 없습니다. 잘못 입력하신 경우 관리자에게 알려 주세요. 명단에서 본인 정보의 삭제를 원하시면 관리자에게 요청하실 수 있으며, 그룹 전체 자료의 삭제는 시스템 관리자에게 요청해 처리합니다.
브라우저 저장
접속 상태 유지를 위해 최소한의 정보만 브라우저에 임시 저장하며, 브라우저 탭을 닫으면 사라집니다. 광고 추적 목적의 쿠키는 사용하지 않습니다.

본 서비스는 개인이 무상으로 제공하는 학교 업무 지원 도구입니다. 학교에서 활용하실 때는 소속 기관의 개인정보 보호 지침에 따라 수집 항목과 보관 방법을 확인하신 뒤 사용해 주시기 바랍니다. 문의: 만든이 최창훈
