우리 학교에 설치하기

안내서를 순서대로 따라가시면 25분이면 끝납니다

🆓 모두 무료 🏫 자료는 학교 계정에만 🙅 이름·이메일 안 받음

준비하실 것

  • 구글 계정 — 저장소(Firebase)를 만들고, 총괄 관리자로 로그인할 때 씁니다.
  • 깃허브(GitHub) 계정 — 완성한 파일을 인터넷에 올릴 때 씁니다. 없으시면 github.com/signup에서 무료로 만드실 수 있습니다.
  • 파일 두 개 — setup.html(설치 파일)과 이 안내서. 아직 안 받으셨다면 아래에서 받으세요.
📥 설치 파일 내려받기 (setup.html)
💡 설치는 한 번만 하면 됩니다. 한 번 올려 두면 해마다 그대로 쓰시면 되고, 학교 규모에서는 Firebase 요금이 나올 일이 없습니다.

설치 순서 한눈에

1Firebase 저장소 만들기
2웹 앱 추가하고 설정값 복사하기
3setup.html 열어 설정 붙여 넣기
4로그인·저장소 기능 켜기
5보안 규칙 붙여넣고 게시하기
6완성된 index.html 내려받기
7깃허브에 올려 주소 만들기
8그 주소를 승인된 도메인에 넣기
9첫 그룹 만들고 교원에게 알리기

1 Firebase 저장소 만들기 5분

우리 학교 자료가 쌓일 곳입니다. 만든이를 포함해 누구에게도 전송되지 않습니다.

  1. console.firebase.google.com에 학교 구글 계정으로 들어갑니다.
  2. [프로젝트 만들기]를 누릅니다.
  3. 이름은 연수비정산처럼 알아보기 쉽게 정합니다.
  4. 구글 애널리틱스는 사용 안 함으로 두셔도 됩니다.
💡 학교 공용 계정으로 만드시면 담당자가 바뀌어도 그대로 넘길 수 있습니다.

2 웹 앱 추가하고 설정값 복사하기 3분

  1. 프로젝트 첫 화면에서 </> 모양 아이콘을 누릅니다.
  2. 앱 이름을 아무렇게나 적고 [앱 등록]을 누릅니다.
  3. const firebaseConfig = { … } 가 나옵니다. 중괄호 부분을 통째로 복사합니다.
⚠️ 이 값은 비밀번호가 아닙니다. 공개되어도 보안 규칙(5단계)이 자료를 지켜 줍니다. 규칙 게시를 꼭 해 주세요.

3 setup.html 열어 설정 붙여 넣기 3분

  1. 내려받은 setup.html을 더블클릭해 브라우저로 엽니다. (인터넷은 연결되어 있어야 합니다)
  2. 설치 마법사 화면이 나옵니다. 3번 칸에 방금 복사한 설정을 붙여 넣습니다.
  3. 4번 칸에 총괄 관리자로 쓸 구글 계정을 적습니다. 학교 전체 그룹을 보고 지울 수 있는 계정입니다. 여러 명이면 쉼표로 구분합니다.
  4. [🔍 설정 확인하기]를 누릅니다. 연결되면 5~7단계가 이어서 나타납니다.
💡 파일을 편집기로 열어 고칠 필요가 없습니다. 마법사가 값을 넣은 파일을 만들어 줍니다.

4 로그인·저장소 기능 켜기 5분

Firebase 콘솔에서 세 가지를 켭니다. 마법사 화면의 [Authentication 열기], [Firestore 열기] 단추를 쓰면 바로 갑니다.

  • Authentication → 시작하기 → 이메일/비밀번호 사용 설정
  • 같은 화면에서 Google 사용 설정 (총괄 관리자 로그인용)
  • Firestore Database → 데이터베이스 만들기 → 위치는 asia-northeast3(서울)

5 보안 규칙 붙여넣고 게시하기 3분

  1. 마법사의 [📋 보안 규칙 복사]를 누릅니다. (총괄 관리자 계정이 들어간 규칙이 만들어집니다)
  2. [규칙 탭 열기]로 이동해 Firestore → 규칙 칸의 내용을 지우고 통째로 붙여 넣습니다.
  3. [게시]를 누릅니다.
⚠️ 이 단계를 건너뛰면 자료가 누구에게나 열립니다. 반드시 게시까지 마쳐 주세요.

6 완성된 index.html 내려받기 1분

마법사 7단계의 [⬇ 설정이 끝난 index.html 내려받기]를 누릅니다. 우리 학교 설정이 모두 들어간 index.html 한 개가 저장됩니다. 이 파일이 우리 학교 프로그램입니다.

💡 setup.html은 설치용이라 올리지 않으셔도 됩니다. 나중에 다시 설치할 일이 있을 수 있으니 컴퓨터에 보관해 두세요.

7 깃허브에 올려 주소 만들기 5분

  1. github.com/new에서 새 저장소를 만듭니다. 이름은 yeonsubi처럼 영문으로 정하고, Public으로 둡니다.
  2. 만들어진 저장소에서 [Add file] → [Upload files]를 누르고, 6단계에서 받은 index.html을 끌어다 놓습니다.
  3. 아래 [Commit changes]를 눌러 저장합니다.
  4. [Settings] → 왼쪽 [Pages]로 갑니다.
  5. Source를 Deploy from a branch, 가지는 main, 폴더는 /(root)로 두고 [Save]를 누릅니다.
  6. 1~2분 뒤 같은 화면 위쪽에 https://계정이름.github.io/저장소이름/ 주소가 나타납니다. 이 주소가 우리 학교 정산 사이트입니다.
⚠️ 저장소가 Public이어도 자료가 공개되는 것이 아닙니다. 공개되는 것은 프로그램 파일뿐이고, 정산 내용은 우리 학교 Firebase에 들어 있으며 보안 규칙과 비밀번호로 막혀 있습니다.
💡 학교 홈페이지나 다른 호스팅에 올리셔도 됩니다. 파일 하나만 올리면 되는 구조라 올릴 수 있는 곳이면 어디든 동작합니다.

8 주소를 승인된 도메인에 넣기 2분

총괄 관리자의 구글 로그인이 되도록 주소를 등록합니다.

  1. Firebase 콘솔 → Authentication → 설정 → 승인된 도메인
  2. [도메인 추가]를 누르고 계정이름.github.io 를 적습니다. (https://와 뒷부분 없이 주소만)
✅ 여기까지 하시면 설치가 끝났습니다. 7단계의 주소로 들어가 보세요.

9 첫 그룹 만들고 교원에게 알리기 3분

  1. 우리 학교 주소로 들어가 [담당자 로그인] → [새 그룹 만들기]를 누릅니다.
  2. 그룹명은 2026 행복초 78처럼 숫자를 섞어 정합니다. 너무 쉬운 이름은 다른 사람이 접속할 수 있습니다.
  3. 관리자 비밀번호와 교원 비밀번호를 정합니다. 잃어버리면 찾을 수 없으니 따로 적어 두세요.
  4. 교원 명단(담당)을 추가합니다. 이름·이메일은 넣지 않습니다.
  5. 교원에게는 주소 · 그룹명 · 교원 비밀번호 세 가지만 알리면 됩니다. 그룹 생성 화면의 [안내문 복사]를 쓰시면 편합니다.
💡 총괄 관리자 화면은 오른쪽 아래 만든이 표기를 다섯 번 연속 누르면 열립니다. 3단계에서 적은 구글 계정으로 로그인합니다.

막히실 때

화면이 하얗게 나옵니다
인터넷 연결을 확인해 주세요. 프로그램이 글꼴·엑셀 기능을 인터넷에서 불러옵니다. 학교 방화벽이 gstatic.com, jsdelivr.net, cdnjs.cloudflare.com을 막고 있으면 열리지 않을 수 있습니다.
설치 마법사에서 "연결하지 못했습니다"가 뜹니다
설정값을 중괄호 { }까지 통째로 붙여 넣으셨는지 확인해 주세요. "Firestore 데이터베이스가 아직 없습니다"가 뜨면 4단계의 Firestore Database → 데이터베이스 만들기를 먼저 해 주세요.
총괄 관리자 구글 로그인이 안 됩니다
8단계 승인된 도메인에 사이트 주소를 넣으셨는지, 4단계에서 Google 로그인을 켜셨는지 확인해 주세요. 그래도 안 되면 3단계에서 적은 구글 계정과 지금 로그인한 계정이 같은지 보십시오.
"권한이 없습니다 / permission denied"가 뜹니다
5단계 보안 규칙을 게시하지 않으셨을 때 나옵니다. 규칙 탭에 붙여 넣고 [게시]까지 눌러 주세요.
관리자 비밀번호를 잃어버렸습니다
비밀번호는 저장만 될 뿐 찾아 드릴 방법이 없습니다. 총괄 관리자 화면에서 그 그룹을 지우고 새로 만드셔야 합니다. 자료는 지우기 전에 엑셀로 내려받아 보관해 주세요.
다음 해에는 어떻게 하나요
사이트는 그대로 두시고 새 학년도 그룹만 새로 만들면 됩니다. 학년도는 3월에 시작해 다음 해 2월에 끝나고, 지난 학년도 그룹은 총괄 관리자 화면에서 한 번에 지울 수 있습니다. 지우기 전에 엑셀로 내려받아 보관해 주세요.
프로그램을 고쳐 써도 되나요
학교 현장에서 쓰시는 범위라면 자유롭게 고쳐 쓰시고 동료에게 나눠 주셔도 됩니다. 다만 상업적 이용은 허락하지 않습니다. 고치실 때는 index.html 하나만 손보면 됩니다.

설치하고 나면 달라지는 것

  • 정산 자료가 학교 계정 안에만 머뭅니다. 만든이도 열어볼 수 없습니다.
  • 학교가 직접 관리하는 것이 되어, 외부에 맡기는 절차가 필요 없습니다.
  • 학년도가 끝나면 학교가 스스로 지울 수 있습니다.
  • 만든이의 사정과 관계없이 계속 쓰실 수 있습니다.
이 프로그램은 이름·이메일 주소·연락처·주민등록번호·계좌번호를 일절 받지 않습니다. 저장되는 것은 그룹명, 담당(1학년 1반 등), 본인 확인용 비밀번호, 지출 항목명·금액·입력 일시뿐입니다.
